ARIO SCRIPTS — static HTML/CSS/JavaScript website

FILES
- index.html      Main public website
- admin.html      Admin dashboard
- style.css       Shared responsive styling
- app.js          Public-site logic
- admin.js        Admin logic
- README.txt      This guide

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser.
3. Open Admin Panel from the top navigation.
4. Add/delete scripts and games from the admin panel.
5. Data is stored in localStorage, so it works without a server.

IMPORTANT
This is a frontend-only demo. The admin panel is NOT secure authentication and should not be used as a real public admin system without a backend/database.
